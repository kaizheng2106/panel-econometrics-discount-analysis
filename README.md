# panel-econometrics-discount-analysis
This project investigates the causal impact of promotional discounts on retail beverage revenue using panel econometric methods.

The analysis uses daily observations from 37 retail stores and addresses cross-sectional dependence through Common Correlated Effects Mean Group (CCEMG) estimation. Homogeneous Granger Non-Causality tests are applied before and after factor correction to distinguish genuine causal effects from spurious significance induced by common shocks.

Results reveal significant inter-temporal demand substitution, where short-term revenue gains are partially offset by reduced future demand.
